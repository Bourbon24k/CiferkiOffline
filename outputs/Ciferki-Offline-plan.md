# Ciferki Offline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** воспроизвести наблюдаемую игру локально и выдать unsigned IPA и исходники.

**Architecture:** WKWebView загружает включённый в приложение веб-интерфейс. Локальный API совместим с форматами данных исходного интерфейса и хранит новое игровое сохранение на устройстве. Серверные социальные механики заменяются виртуальными игроками.

**Tech Stack:** UIKit, WebKit, JavaScript, Xcode, Node.js для тестов игровой логики.

**Spec:** Ciferki-Offline-design.md

## Global Constraints

- Игра работает без сети и без Telegram-аутентификации.
- Начинается новое локальное сохранение; живой аккаунт не изменяется.
- Скрытые алгоритмы реконструируются; отличия раскрываются в описании результата.
- Результат содержит настоящий arm64 .app, упакованный в Payload внутри unsigned IPA.

## Review Focus

- Недостаточный баланс: действие не изменяет коллекцию и не уводит баланс в минус.
- Пакетная крутка: стоимость списывается один раз за каждый результат.
- Повреждение сохранения: используется резервная копия, ошибка не скрывается.
- Повтор награды: одна дневная награда на локальную календарную дату.
- Работа без сети: каждый игровой экран использует встроенные данные и локальные расчёты.
